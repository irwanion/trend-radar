# Shopee Affiliate Trend Radar
Daily list of 8 home decor, tools and kitchen appliance products with rising demand in Indonesia (Google Trends).
- `harvester/` collects and scores the data (edit `config.json` to change keywords)
- `docs/` is the dashboard (GitHub Pages) and `docs/data/` holds the last 7 days
- `.github/workflows/daily.yml` runs the harvester every day
